# Requisitos

## Requisitos Funcionais (RF)

### RF01 – Autenticação
- O sistema deve permitir cadastro de usuários.
- O sistema deve permitir login e logout.
- O sistema deve permitir recuperação de senha.
- O sistema deve permitir alteração de senha.

### RF02 – Gerenciamento de Usuários
- Cadastrar usuários.
- Editar usuários.
- Excluir usuários.
- Gerenciar perfis e permissões.

### RF03 – Gerenciamento de Projetos
- Criar projetos.
- Editar projetos.
- Arquivar projetos.
- Excluir projetos.
- Adicionar membros aos projetos.

### RF04 – Gestão de Casos de Teste
- Criar casos de teste.
- Editar casos de teste.
- Excluir casos de teste.
- Organizar casos por suítes.
- Definir prioridade e status.

### RF05 – Execução de Testes
- Executar casos de teste.
- Registrar resultado da execução.
- Adicionar observações.
- Registrar data, horário e responsável.

### RF06 – Gestão de Bugs
- Registrar bugs.
- Editar bugs.
- Alterar status dos bugs.
- Definir prioridade e severidade.
- Vincular bugs a casos de teste.

### RF07 – Gestão de Demandas
- Criar demandas.
- Editar demandas.
- Atribuir responsáveis.
- Alterar status.
- Definir prioridade.

### RF08 – Evidências
- Anexar imagens.
- Anexar documentos.
- Anexar vídeos.
- Visualizar evidências.
- Excluir evidências.

### RF09 – Relatórios
- Gerar relatórios automaticamente.
- Exportar relatórios.
- Exibir métricas de testes.
- Exibir indicadores de qualidade.

### RF10 – Dashboard
- Exibir indicadores do projeto.
- Mostrar gráficos.
- Exibir quantidade de bugs.
- Exibir taxa de sucesso dos testes.

### RF11 – Pesquisa
- Pesquisar projetos.
- Pesquisar casos de teste.
- Pesquisar bugs.
- Aplicar filtros.

### RF12 – Histórico
- Registrar histórico de alterações.
- Exibir histórico por usuário.
- Exibir histórico por projeto.

### RF13 – Notificações
- Notificar novas atribuições.
- Notificar novos bugs.
- Notificar alterações importantes.

# Requisitos Não Funcionais (RNF)

### RNF01 – Desempenho
- As páginas deverão carregar em até 3 segundos em condições normais.

### RNF02 – Responsividade
- O sistema deverá funcionar em computadores, tablets e smartphones.

### RNF03 – Segurança
- As senhas deverão ser criptografadas.
- O sistema deverá utilizar autenticação segura.
- As permissões deverão ser controladas por perfil.

### RNF04 – Disponibilidade
- O sistema deverá estar disponível continuamente, salvo períodos de manutenção.

### RNF05 – Usabilidade
- A interface deverá ser intuitiva e de fácil utilização.

### RNF06 – Compatibilidade
- O sistema deverá funcionar nos principais navegadores modernos.

### RNF07 – Escalabilidade
- O sistema deverá suportar crescimento no número de usuários e projetos.

### RNF08 – Manutenibilidade
- O código deverá seguir padrões de desenvolvimento para facilitar manutenção e evolução.

### RNF09 – Confiabilidade
- O sistema deverá garantir a integridade das informações armazenadas.

### RNF10 – Backup
- O sistema deverá permitir backup e recuperação dos dados.

### RNF11 – Auditoria
- O sistema deverá registrar ações críticas realizadas pelos usuários.

### RNF12 – Acessibilidade
- O sistema deverá seguir boas práticas de acessibilidade (WCAG), permitindo navegação por teclado e contraste adequado.
